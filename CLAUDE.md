# AI Agent Lab

A learning sandbox for building agentic AI systems from scratch: raw
Anthropic API tool-use loops (no LangChain/LangGraph), LLM guardrails, RAG,
and red-teaming techniques like indirect prompt injection and data
poisoning. The point is to understand and be able to explain every layer,
not to generate a finished system to skim — also a chance to get more
comfortable with Python and bash along the way.

Everything here is local, sandboxed, and non-destructive. Any "malicious"
content used later for red-teaming/poisoning tests will be a
proof-of-concept payload only, never a real exploit against a real system.
